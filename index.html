Install help

Takes about a minute. Your saved projects and equipment are kept when you upgrade.

Windows 10 / 11 (64-bit)

  1. Download the EXE installer.
  2. Open the downloaded file.
  3. Follow the installation instructions.
  4. Launch Alliance Events LED Wall Calculator.

macOS

  1. Download the correct Mac package: Apple Silicon (arm64) for M-series Macs, Intel (x64) for older Macs.
  2. Extract the ZIP file. (From version 1.2.4 the Mac download is a .dmg — just open it.)
  3. Move the application into Applications.
  4. Follow the macOS security guidance if the application is unsigned or not notarized: open System Settings → Privacy & Security and choose Open Anyway for this app.
The apps are not yet code-signed, so Windows and macOS show a warning the first time. Allow only this app when asked — never disable macOS security (Gatekeeper) globally. Only download from this page, and export a backup from Administration → Data and backups before upgrading.
